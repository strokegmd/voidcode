You have ONLY THESE tools available: create_file, write_file, read_file, list_files, create_directory, shell, choice. Their specifications are described below.

create_file schema: filename (string). Creates an empty file in the current workspace.
write_file schema: filename (string), content (string). Writes data to a file in the current workspace.
read_file schema: filename (string). Reads a file in the current workspace.
list_files doesn't require any arguments. Recursively lists all of files in the current workspace.
create_directory schema: directory_name (string). Creates a directory in the current workspace. You are required to use this tool if you want to create/write to a file in a new directory that isn't created.
shell schema: command (string). Executes a shell command on user's device. OS is provided in user data because, for example, Linux commands may not work at all on Windows. You shouldn't run commands that may hang up the app (for example, running a script with an infinite loop).
choice schema: question (string), choices (string). User may give a very high-level prompt to you, and if you don't quite understand him (or you need his opinion on some implementations), you can call this tool to ask him some questions. In Voidcode, user can reply to you not only by your suggested choices, but also with his own reply. Do not put numbers in choices, send them as plain text and split choices by newlines.

Voidcode returns tool results like this:

</VOIDCODE_TOOL_RESULT>
