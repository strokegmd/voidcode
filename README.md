# Voidcode
An attempt to reverse web UIs of most popular LLMs and create AI-powered coding agent.

# LLMs supported
- DeepSeek (web version) with DeepThink 
- Qwen 3.8 Max (and all from [chat.qwen.ai](https://chat.qwen.ai) website)

# Plans
Currently it's an absolutely not usable in production tool. I don't really see any point in supporting it.

# Using
If you decided to use this piece of shit, then just install everything from requirements.txt and configure tokens in config.json.
