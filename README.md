# Voidcode
An attempt to reverse web versions of LLMs and create AI-powered coding assistant.

# LLMs supported
- DeepSeek V3 with DeepThink 
- Qwen 3.7 Max (and all from [chat.qwen.ai](https://chat.qwen.ai) website)

# Plans
Currently it's an absolutely not usable in production tool. I am planning to reverse [chatgpt.com](https://chatgpt.com) and add it support.

Also I am planning to fully rewrite the tool calling protocol because it is very shitty and Qwen breaks it.

# Using
If you decided to use this piece of shit, then just install everything from requirements.txt and configure tokens in config.json.

By default it is using Qwen token, to use DeepSeek you need to edit main function in main.py xd.
